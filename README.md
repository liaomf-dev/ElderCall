# 長輩電話 App（Android）

大字、大按鈕的電話 App。主畫面上半是聯絡人（點一下直接撥出），下半是撥號鍵盤；
設為預設電話後，來電與通話中也會顯示大字畫面。

## 功能
- 聯絡人大按鈕：照片＋名字，點一下直接撥出
- 常駐大撥號鍵盤
- 大字來電畫面：接聽／拒接
- 大字通話畫面：掛斷、擴音、按鍵（語音選單用）、通話時間
- 家人設定（主畫面按住「設定」1 秒）：新增、修改、刪除聯絡人；可選相簿照片或從手機通訊錄匯入

## 第一次使用
1. 允許「電話」「通訊錄」「通知」權限
2. 依提示把「長輩電話」設為預設電話 App
3. 按住右上角「設定」新增聯絡人

## 編譯
上傳到 GitHub，建立 `.github/workflows/build.yml`，到 Actions 下載 `ElderCall-apk`。

## 注意
- 設為預設電話後，手機原本的電話 App 不會再負責來電畫面；想換回來，到手機設定 → 應用程式 → 預設應用程式 → 電話。
- 需要 Android 7.0 以上；來電大字畫面在 Android 10 以上最穩定。
